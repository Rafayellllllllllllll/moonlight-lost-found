# 月光失物招领所 Moonlight Lost & Found

纯前端网页小游戏：梦幻探索、轻度解谜、收藏养成与分支叙事。React + TypeScript + Vite，无后端、无登录，进度存在浏览器 localStorage。

## 玩法

午夜古董店 → 接待访客 → 点失物找线索（至少 3 条）→ 解开真实谜题 → 选择对话 → 迎来不同结局 → 领藏品与星尘 → 布置小店、完成图鉴。

首发 5 个故事、5 个真实谜题、10 种结局、24 件藏品（含隐藏组合）：

1. 遗失星光的玻璃瓶：旋转三层星盘
2. 停在午夜的怀表：调 11:47 与铜+银齿轮
3. 缺失人物的旧照片：3×3 拼图 + 隐藏签名
4. 不会唱歌的水晶鸟：听旋律、按顺序点音符（3 关）
5. 没有影子的月亮：调光源、镜面、遮挡物照亮目标

另有今日梦境挑战（每天一局星盘，奖励 30 星尘）、星尘装饰商店、稀有度筛选图鉴。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可游玩；手机与桌面浏览器均可，点按操作为主。

## 构建

```bash
npm run build
npm run preview
```

## 存档

键名 `moonlight-lost-found-save-v1`，存在本设备浏览器 localStorage。刷新后点“继续游戏”即可；设置里可以清空存档重开。音效为程序合成（Web Audio），背景音乐需在页面上点一下后开始，符合浏览器自动播放限制。
